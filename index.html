How it works

        
Your HLSL pixel shader is translated to GLSL ES 3.0 in the browser and rendered with WebGL2 over the full canvas. Nothing is uploaded anywhere.

        
Entry point

        
    
          
  • float4 main(float2 uv : TEXCOORD0) : SV_Target – also accepts float3/float returns, struct inputs, SV_Position. Names tried: main, PSMain, pixel, frag… (otherwise the last float4 function).
    • 
          
  • void mainImage(out float4 fragColor, in float2 fragCoord) – Shadertoy style.
    • 
          
  • uv / SV_Position follow HLSL: origin top-left, y down.
    • 
        

        
Built-in uniforms

        
    
          
  • float iTime, float iTimeDelta, int iFrame
    • 
          
  • float3 iResolution (pixels), float4 iMouse (pixels, origin bottom-left, Shadertoy convention)
    • 
        

        
Your own parameters → UI controls

        
    
          
  • Top-level float / float2-4 / int / uint / bool globals and cbuffer members become uniforms with sliders. Initializers are the defaults.
    • 
          
  • Add // range(min, max) on the same line to set slider limits. Names containing color / tint / albedo / rgb get a color picker.
    • 
          
  • Texture2D t; SamplerState s; + t.Sample(s, uv) work. All textures share one image: use “Load image” in Controls.
    • 
        

        
Translated automatically

        
float2/3/4, int/uint/bool vectors, floatNxN matrices, lerp frac saturate rsqrt mul mad fmod atan2 ddx ddy clip sincos rcp log10 tex2D, (float3)x casts, float3 x = 0;, static, [unroll], semantics, register().

        
Known limits

        
    
          
  • GLSL ES is stricter than HLSL: no implicit int→float (write 1.0, not 1), no pow(v3, 2.0) with a scalar exponent, no vector comparisons like a < b.
    • 
          
  • Matrix indexing M[i] is column-wise in GLSL (HLSL is row-wise). mul() and matrix constructors are handled consistently.
    • 
          
  • No #include, compute/geometry stages, or multiple render targets.
    • 
          
  • Errors are shown with your HLSL line numbers. The GLSL tab shows what is actually compiled.
    • 
        

        
Ctrl/Cmd+Enter recompiles immediately. Your code is autosaved in this browser.
